name: PAINT
kind: command

Paint is a full-screen, mouse-driven pixel paint application in the spirit of
Dr. Halo / Dr. Genius. It runs at 640x360: one canvas pixel is exactly one
screen pixel, and colours are indices into the fixed default VGA 256 palette.

PAINT [file$]

  file$ - optional file name (PCX). Default A:/PAINT.PCX.

Layout. A text menu bar runs across row 0 (File, Edit and Help). The tool
column runs down the left edge. The 256-colour palette is a strip of 4 rows x
64 swatches across the bottom, with the foreground/background indicator at its
left end. The canvas is the remaining area and starts black (palette index 0).

PAINT needs a mouse. If no pointer is detected it prints a clear message and
returns to the prompt without disturbing the screen.

Colour. Two colours are always active. The indicator at the left end of the
palette shows the background as an outer square and the foreground as an inner
square. On a mouse:

  left click swatch     select the foreground (FG)
  right click swatch    select the background (BG)
  click the indicator   swap FG and BG
  left drag canvas      draw with FG
  right drag canvas     draw with BG

Tools. Choose a tool by clicking its icon in the left column. Line, rectangle,
ellipse and circle show a live rubber-band preview and commit on release;
hold Shift to constrain to square, circle or 45 degrees. Flood fill matches the
exact colour. The eyedropper samples the canvas into FG.

Menus. Click a menu to open it, hover to switch, and click away or press Esc to
close. Keyboard navigation is supported:

  File   New canvas, Open, Save, Save as, Quit
  Edit   Undo, Redo, Clear
  Help   Keys

Open, Save and Save as use an EDIT-style file dialog that can browse any
location (A:, C:, USB). PAINT reads and writes 8-bit indexed PCX files, so a
sketch keeps its palette when it round-trips. Undo keeps eight steps.

  Esc, Alt+X   leave PAINT and return to the prompt

Example:

    PAINT
    PAINT "A:/SKETCH.PCX"
