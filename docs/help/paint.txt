name: PAINT
kind: command

Dr. Genie / Paintbrush-style pixel paint app. PAINT opens a full-screen
canvas; every canvas pixel is one character cell drawn in a fixed 16-colour
palette. A USB mouse drives the same tools (click to draw, drag to paint,
right-click to pick a colour); without a mouse the keyboard works on its
own.

PAINT [file$] [, width [, height]]

  file$  - PNG path (with or without .PNG). Default A:/PAINT.PNG. An existing
           file is loaded; its size becomes the canvas when no size is given.
  width  - optional canvas width in pixels, 1..96
  height - optional canvas height in pixels, 1..48

Tools select with a single key:

  p  pencil       e  eraser       l  line        r  rectangle
  o  circle       f  flood fill   i  colour picker
  u, Ctrl+Z undo  x  clear canvas s  save

  Arrows      move the cursor
  Space/Enter apply the tool. For line/rectangle/circle the first press sets
              the anchor and the second draws from the anchor to the cursor.
  0-9         pick colour 0..9
  [ ]         cycle through the 16 colours
  Alt+X, Esc  leave PAINT and return to the prompt

A loaded image is quantised to the nearest of the 16 palette colours. Saving
writes a plain RGB PNG the same size as the canvas, so a sketch reloads
exactly where it was left.

Example:

    PAINT
    PAINT "A:/SKETCH.PNG"
    PAINT "A:/ICON.PNG", 32, 32
