name: PAGE
kind: command

Select off-screen pages for drawing and display, copy or scroll pages, and
combine pages with AND/OR/XOR.

PAGE WRITE n | FRAMEBUFFER
PAGE DISPLAY n
PAGE COPY src [TO dst]
PAGE COPY src, dst [, I|B]
PAGE SCROLL n, x, y [, fillcolour]
PAGE AND_PIXELS s1, s2, dest
PAGE OR_PIXELS  s1, s2, dest
PAGE XOR_PIXELS s1, s2, dest

  n - page number
  src, dst - source and destination pages
  B - skip black pixels (CMM2 blit)
  x, y - SCROLL moves the page right by x and up by y
  fillcolour - omitted wraps; -1 leaves the gap; any other colour fills it

WRITE selects the draw target (a page number or FRAMEBUFFER). DISPLAY shows
page n. Page 1 is composited over the display page: black is clear,
RGB(...,t) blends.

Example:

    PAGE COPY 0 TO 1
    PAGE SCROLL 0, 8, 0
