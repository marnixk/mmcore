name: SELECT CASE
kind: language
alias: SELECT, CASE, CASE ELSE, END SELECT

Choose a branch matching an expression.

SELECT CASE expr
CASE value [, value...]
CASE IS relop expr
CASE ELSE
END SELECT

  expr - value to match
  value - literal or range low TO high (inclusive)
  relop - =, <>, <, >, <=, >=

Example:

    N = 2
    SELECT CASE N
    CASE 1
      PRINT "ONE"
    CASE 2 TO 4
      PRINT "TWO"
    CASE IS > 10
      PRINT "BIG"
    CASE ELSE
      PRINT "OTHER"
    END SELECT
