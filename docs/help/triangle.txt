name: TRIANGLE
kind: command

Draw a triangle, optionally filled.

TRIANGLE x1, y1, x2, y2, x3, y3 [, colour] [, fill]

  x1, y1, x2, y2, x3, y3 - three vertices
  colour - outline colour (optional)
  fill - fill colour if >= 0 (optional)

Example:

    TRIANGLE 10, 80, 40, 80, 25, 50, RGB(255, 255, 0)
