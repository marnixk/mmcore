name: BITMAP
kind: command
alias: GUI, GUI BITMAP

Plot a 1-bit bitmap at a pixel location. Bits are drawn MSB-first in each byte,
top line first.

BITMAP x, y, bits [, w] [, h] [, scale] [, c] [, bc]
GUI BITMAP ...

  x, y - top-left pixel
  bits - integer mask or string of bytes
  w, h - width and height in pixels (default 8x8)
  scale - integer scale (default follows FONT)
  c - foreground colour (optional)
  bc - background colour (optional)

Example:

    BITMAP 20, 20, &HFF000000000000FF, 8, 8, 2, RGB(255, 255, 255)
