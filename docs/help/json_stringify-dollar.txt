name: JSON_STRINGIFY$
kind: command

Turn a TYPE variable into a JSON string. Keys are the member names.
Integers have no decimal. The result grows as needed (a hard internal cap
raises ?OVERFLOW). JSON$ can query the result.

JSON_STRINGIFY$(var)

  var - TYPE variable

Returns the JSON text as a string.

Example:

    s$ = JSON_STRINGIFY$(w)
    PRINT JSON$(s$, "temp")
