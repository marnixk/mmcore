name: JSON_STRINGIFY$
kind: command

Turn a TYPE variable into a JSON STRING (255). Keys are the member names.
Integers have no decimal. Longer than 255 characters is an error. JSON$ can
query the result.

JSON_STRINGIFY$(var)

  var - TYPE variable

Returns the JSON text as a string.

Example:

    s$ = JSON_STRINGIFY$(w)
    PRINT JSON$(s$, "temp")
