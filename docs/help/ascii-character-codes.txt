Use ~CHR$~(n) to build a character from a code, and
~ASC~(s$) to read the code of the first character.

In the editor, hold Ctrl+Alt for 1.5 seconds to open the
character picker: choose with the arrow keys, press Enter to
insert, and release Ctrl+Alt to close.

Example:

    PRINT CHR$(65)
    PRINT ASC("A")
    PRINT CHR$(219)
