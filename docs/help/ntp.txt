name: NTP
kind: command

Synchronise the clock from a Network Time Protocol server. Requires Ethernet
or Wi-Fi (see ~ETHERNET~ / ~OPTIONS~ WIFI) and runs best-effort: when the
network is down the clock is left unchanged and an error is reported.

NTP
OPTION NTP ON|OFF
OPTION NTP SERVER "host[:port]"
OPTION TIMEZONE "name"

The NTP command performs a one-shot sync from OPTION NTP SERVER (default
pool.ntp.org, port 123) and prints the resulting local time.

OPTION NTP ON enables a best-effort sync at boot once the network is up.
OPTION TIMEZONE selects the zone used by ~DATE$~, ~TIME$~ and ~DATETIME$~;
~EPOCH~ and the stored clock stay UTC. Timezone names come from a built-in
fixed-offset table without daylight saving, for example UTC (the default),
Europe/Amsterdam or Pacific/Auckland; a numeric offset such as UTC+2 or
UTC-5:30 also works.

There is no battery-backed RTC in the base machine, so the clock restarts at
boot and NTP re-syncs it. File timestamps follow the synced local clock.

Example:

    OPTION NTP SERVER "pool.ntp.org"
    OPTION TIMEZONE "Europe/Amsterdam"
    OPTION NTP ON
    NTP
    PRINT TIME$

See also ~TIMEZONE~, ~DATETIME$~, ~EPOCH~.
