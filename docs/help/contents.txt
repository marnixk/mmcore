Prompt
  OPTION PROMPT BARE|CWD         "> " or DOS $p$g (A:/>)
  HELP ~PROMPT~ for details. Persists in .mmbasic.ini.
  Up/Down history; Left/Right move; typing inserts.

Wi-Fi / Ethernet
  OPTION WIFI "ssid","password"  store and connect
  OPTION WIFI                    scan and prompt
  OPTION WIFI DEBUG ON|OFF       [wifi] logs; TERM !NET / !TCP
  OPTION WIFI COUNTRY "NZ"       ISO domain (default US; UK=GB)
  OPTIONS WIFI                   connect with stored credentials
  OPTION ETHERNET ON|OFF         wired DHCP (Pi with RJ45)
  IPCONFIG                       active interface, IP, gateway, DHCP
  One interface at a time. Ethernet ON disables Wi-Fi join.
  Credentials persist in C:/.mmbasic.ini (A: if no SD).
  OPTIONS WIFI joins using stored SSID/PSK.
  ?WIFI not configured if none are stored.
  Scan lists beacon SSIDs. WPA2 join needs C: and
  C:/firmware/. QEMU has no Wi-Fi radio. Ethernet
  needs QEMU -device usb-net (else not available).
  HELP ~OPTION~. HELP ~ETHERNET~. HELP ~IPCONFIG~.
