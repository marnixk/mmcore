name: IPCONFIG
kind: command

Show the active network interface. Only one of Wi-Fi or Ethernet is up at a
time.

IPCONFIG

Prints Interface: Ethernet | Wi-Fi. "Connected as <ip>" appears only when the
link is up and a live gateway probe succeeds (ARP/ICMP), not merely because
DHCP bound once. If the lease is cached but the gateway does not answer: Not
connected / gateway unreachable, plus the DHCP IP. Ethernet also shows MAC,
netmask, DNS, DHCP, and link speed when known. Wi-Fi shows SSID and country.
OPTION WIFI DEBUG ON adds WPA vs DHCP lines for Wi-Fi.

If the radio or NIC is missing: Wi-Fi not available or Ethernet not available.
QEMU Ethernet needs -device usb-net. If the link is down: Not connected.
Join Wi-Fi with OPTIONS WIFI, or OPTION ETHERNET ON.

Example:

    IPCONFIG
