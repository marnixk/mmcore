name: RGB
kind: command

Build a colour value from red, green and blue, or a colour name.

colour = RGB(red, green, blue)
colour = RGB(name$)
colour = RGB(number)

  red, green, blue - 0..255
  name$            - a colour name such as "RED"

See also ~COLOUR~, ~THEME~.

Example:

    PRINT RGB(255, 0, 0)
    PRINT RGB("YELLOW")
