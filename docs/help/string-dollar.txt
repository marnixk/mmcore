name: STRING$
kind: command

Return a string by repeating a character or a string.

string$ = STRING$(n, char)
string$ = STRING$(n, string$)

  n       - repeat count
  char    - character code, or a one-character string
  string$ - repeated as a whole n times when longer than one character

See also ~SPACE$~.

Example:

    PRINT STRING$(4, "*")
    PRINT STRING$(2, "ab")
