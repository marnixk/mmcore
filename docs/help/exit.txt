name: EXIT
kind: language
alias: EXIT DO, EXIT FOR, EXIT SUB, EXIT FUNCTION

Leave the current DO, FOR, SUB, or FUNCTION immediately.

EXIT DO
EXIT FOR
EXIT SUB
EXIT FUNCTION

Example:

    FOR I = 1 TO 10
      IF I = 3 THEN EXIT FOR
      PRINT I
    NEXT I

    DO
      IF INKEY$() <> "" THEN EXIT DO
    LOOP

    SUB Demo
      IF X < 0 THEN EXIT SUB
      PRINT X
    END SUB

    FUNCTION Half(N)
      IF N <= 0 THEN EXIT FUNCTION
      Half = N / 2
    END FUNCTION
