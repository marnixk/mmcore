name: OPTION
kind: command

OPTION setting ...
OPTION LIST [ALL]
OPTION RESET

Interpreter settings. Implemented subcommands:
  BASE 0|1          EXPLICIT [ON|OFF]
  DEFAULT INTEGER|FLOAT|STRING|NONE
  DEFAULT MODE n    DEFAULT COLOURS fg [, bg]
    Default MODE is 11 (1280x720).
  ANGLE DEGREES|RADIANS    Y_AXIS UP|DOWN
  TAB 2|3|4|8       BREAK n     AUTORUN ON|OFF
  (BREAK n is the cooked key; PrtScr always breaks)
  COLOURCODE ON|OFF|REVERSE
  CONSOLE SCREEN|SERIAL|BOTH|NONE|SAVE|PORT n
  CRLF CRLF|CR|LF   BAUDRATE n  CASE UPPER|LOWER|TITLE
  LEGACY ON|OFF     MILLISECONDS ON|OFF
  MOUSE OFF|n [, sens]   PIN n   PROFILING ON|OFF
  TRACECACHE ON|OFF     pin vars in hot numeric LET/IF
  PROMPT BARE|CWD   immediate prompt (see HELP PROMPT)
    CWD (default) is DOS $p$g: drive and path then
    >, e.g. A:/> or A:/PRDIR>. BARE is "> ". Stored
    as prompt=0|1 in .mmbasic.ini. OPTION LIST shows
    BARE when selected; LIST ALL always shows the mode.
  RAM   FLASH [page]     STATUS ON|OFF
  VCC n    SLEEP n    SD TIMING FAST|NORMAL
  SERIAL PULLUP ENABLE|DISABLE
  RTC CALIBRATE n   DS3231 ON|OFF   BASELINE ON|OFF
  USBKEYBOARD US|UK|DE|FR|ES [, NOLED]
  KEYBOARD REPEAT first [, next]
    Default 300,75 ms (first delay, then repeat).
  EDIT FONT SMALL|NORMAL|MEDIUM|LARGE|VERY LARGE
  EDIT THEME name|n   (10 editor colour themes;
    default Slate)
  ESCAPE    SEARCH PATH path$    ERROR CONTINUE|ABORT
  F1..F12 string$    AUDIO ON|OFF
  AUDIO_TARGET HDMI|JACK   (HDMI0 or 3.5mm PWM jack)
  AUDIO TARGET HDMI|JACK   (same)
  DISPLAY/LCDPANEL/TOUCH/SDCARD/RESOLUTION/CLOCK/
  CPUSPEED/HEARTBEAT (other hardware lines are parsed)
  WIFI [ssid$ [, password$]]
    No args: scan beacons and prompt (needs radio).
    Lists printable SSIDs from the CYW4343x escan
    result, not random bytes in the scan blob.
    With args: store credentials in .mmbasic.ini
    and join with WPA2. Circle needs a 2-letter ISO
    country it will associate (default US; use GB
    not UK). OPTION WIFI COUNTRY "NZ" persists in
    the INI and wpa_supplicant.conf.
    Hardware images ship C:/firmware/.
    QEMU has no Wi-Fi radio.
    Use OPTIONS WIFI to join stored credentials.
  WIFI COUNTRY "XX"
    Regulatory domain Circle accepts. Default US.
    UK is stored as GB. Unknown codes are rejected.
  WIFI DEBUG ON|OFF
    Print [wifi] progress on HDMI and serial.
    Default OFF. The PSK is never printed.
    On a live TERM TCP session it also prints
    compact !NET rx/tx/parsed counters; the pane
    is not copied to serial.
    Live CONNECT/TERM also emit serial-only !TCP
    snapshots every 0.5s: bytes/zero/err from
    Circle Receive, leftover frame, and socket
    GetStatus (conn/rxrdy/txrdy). HDMI is unchanged.
  ETHERNET ON|OFF
    Use the RJ45 port (Pi 3/3B+/4; USB LAN on Pi 3).
    ON starts DHCP and turns off Wi-Fi auto-join.
    OFF leaves the cable unused (reboot to free the
    stack if Ethernet is already up). Only one of
    Wi-Fi or Ethernet is active. QEMU has no
    onboard NIC; -device usb-net provides USB
    CDC Ethernet.
    Persists as [ethernet] enabled= in .mmbasic.ini.
  TERM LOG ON|OFF
    C:/.termlog (A: if no SD). RAM buffer, flush
    every 10s. R|T ms in_total rendered hex. Default OFF.

Settings persist in C:/.mmbasic.ini (A: if no SD).
FACTORY_RESET restores defaults and rewrites the INI.

Example:  OPTION BASE 1
          OPTION WIFI COUNTRY "NZ"
          OPTION WIFI "MyNet","secret"
          OPTIONS WIFI
          OPTION WIFI DEBUG ON
          OPTION ETHERNET ON
          OPTION TERM LOG ON
          OPTION PROMPT CWD
          OPTION LIST
