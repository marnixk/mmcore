name: OPTION
kind: command

Change interpreter settings. Settings persist across reboots. FACTORY_RESET
restores defaults.

OPTION setting ...
OPTION LIST [ALL]
OPTION RESET

Settings:
  BASE 0|1          EXPLICIT [ON|OFF]
  DEFAULT INTEGER|FLOAT|STRING|NONE
  DEFAULT MODE n    DEFAULT COLOURS fg [, bg]
    Default MODE is 11 (1280x720).
  ANGLE DEGREES|RADIANS    Y_AXIS UP|DOWN
  TAB 2|3|4|8       BREAK n     AUTORUN ON|OFF
    (BREAK n is the cooked key; PrtScr always breaks)
  COLOURCODE ON|OFF|REVERSE
  CONSOLE SCREEN|SERIAL|BOTH|NONE|SAVE|PORT n
  CRLF CRLF|CR|LF   BAUDRATE n  CASE UPPER|LOWER|TITLE
  LEGACY ON|OFF     MILLISECONDS ON|OFF
  MOUSE OFF|n [, sens]   PIN n   PROFILING ON|OFF
  TRACECACHE ON|OFF
  PROMPT BARE|CWD   immediate prompt (see ~PROMPT~)
    CWD (default) is DOS $p$g: drive and path then >, e.g. A:/> or A:/PRDIR>.
    BARE is "> ". OPTION LIST shows BARE when selected; LIST ALL always shows
    the mode.
  RAM   FLASH [page]     STATUS ON|OFF
  VCC n    SLEEP n    SD TIMING FAST|NORMAL
  SERIAL PULLUP ENABLE|DISABLE
  RTC CALIBRATE n   DS3231 ON|OFF   BASELINE ON|OFF
  USBKEYBOARD US|UK|DE|FR|ES [, NOLED]
  KEYBOARD REPEAT first [, next]
    Default 300,75 ms (first delay, then repeat).
  EDIT FONT SMALL|NORMAL|MEDIUM|LARGE|VERY LARGE
  EDIT THEME name|n   (10 editor colour themes; default Slate)
  ESCAPE    SEARCH PATH path$    ERROR CONTINUE|ABORT
  F1..F12 string$    AUDIO ON|OFF
  AUDIO_TARGET HDMI|JACK   (HDMI0 or 3.5mm PWM jack)
  AUDIO TARGET HDMI|JACK   (same)
  DISPLAY/LCDPANEL/TOUCH/SDCARD/RESOLUTION/CLOCK/
  CPUSPEED/HEARTBEAT
  WIFI [ssid$ [, password$]]
    No args: scan for networks and prompt (needs radio). With args: store
    credentials and join with WPA2. Use OPTIONS WIFI to connect with stored
    credentials.
  WIFI COUNTRY "XX"
    Set the Wi-Fi regulatory domain (default US; use GB for United Kingdom).
    Unknown codes are rejected.
  WIFI DEBUG ON|OFF
    Print [wifi] progress on HDMI and serial. Default OFF. The password is
    never printed.
  ETHERNET ON|OFF
    Use the Ethernet port. ON starts DHCP and turns off Wi-Fi auto-join. OFF
    leaves the cable unused (reboot to free the stack if Ethernet is already
    up). Only one of Wi-Fi or Ethernet is active. The setting is saved across
    reboots.
  NTP ON|OFF
    Sync the clock from the network at boot (best-effort). Default OFF.
  NTP SERVER "host[:port]"
    Server for ~NTP~ (default pool.ntp.org, port 123).
  TIMEZONE "name"
    Local zone for DATE$/TIME$/DATETIME$ (default UTC; no daylight saving).
    See ~TIMEZONE~.
  TERM LOG ON|OFF
    Write session traffic to C:/.termlog (A: if no SD). Default OFF.
  TERM AUTOLOG ON|OFF
    Start a fresh TERM log automatically for each new session. Default OFF.
  TERM SCROLLBACK n
    Lines of TERM history kept for Page Up / search. Default 200, 0 off.

Example:

    OPTION BASE 1
    OPTION WIFI COUNTRY "NZ"
    OPTION WIFI "MyNet", "secret"
    OPTIONS WIFI
    OPTION WIFI DEBUG ON
    OPTION ETHERNET ON
    OPTION TERM LOG ON
    OPTION TERM SCROLLBACK 400
    OPTION PROMPT CWD
    OPTION LIST
