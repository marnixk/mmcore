name: CAT
kind: command

Append one string onto another in place (same as s$ = s$ + t$).

CAT s$, t$

  s$ - destination string variable
  t$ - text to append

Example:

    A$ = "MM" : CAT A$, "BASIC" : PRINT A$

At the prompt only (not inside a running program), CAT with no comma prints a
whole file to the screen, like the Linux command:

    CAT "notes.txt"

The path may be quoted or bare; no switches are used.
