name: AUDIO_TARGET
kind: command
alias: AUDIO

Select where PLAY sends PCM. The choice is saved across reboots.
PRINT MM.INFO$("AUDIO") returns HDMI or JACK.

OPTION AUDIO_TARGET HDMI|JACK
OPTION AUDIO TARGET HDMI|JACK
OPTION AUDIO ON|OFF

  HDMI - HDMI0 audio (default)
  JACK - 3.5mm PWM analogue output on Pi 3 and Pi 4B (Pi 400 has no jack)
  AUDIO OFF - mutes output; PLAYING() reflects decode state

Example:

    OPTION AUDIO_TARGET JACK
    PLAY TONE 440, 440, 500
