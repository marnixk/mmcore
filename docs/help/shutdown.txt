name: SHUTDOWN
kind: command

Power off the machine. Saves settings, stops audio, and unmounts drives first,
then turns off power. Control does not return to the prompt.

Supported on the bare Raspberry Pi build and on the Linux framebuffer live
USB / installed Alpine image (`mmcore-fb`). On Raspberry Pi 5 the board powers
off; on earlier Pi models the CPU halts and you remove power. The native
Linux, macOS, and Windows desktop apps do not support hardware shutdown; use
the host's own power controls instead.

SHUTDOWN

Example:

    SHUTDOWN
