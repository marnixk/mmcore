name: INPUT
kind: command

Read values from the console or from an open file/TCP stream. LINE INPUT reads
a whole line into a string. See ~INPUT$~ for INPUT$(nbr, #n).

INPUT [prompt$;|,] var [, var...]
INPUT #n, var [, var...]
LINE INPUT [prompt$] var$
LINE INPUT #fn, var$

  prompt$ - optional prompt; ; after it prints ?, comma skips the ?
  var - variable(s) to fill from comma-separated fields
  #n / #fn - open file or TCP stream

Console INPUT prints an optional prompt, then ? if the prompt is followed by ;
(or if there is no prompt). Type a line; comma-separated fields fill the vars.

Example:

    INPUT "Name"; N$
    PRINT N$
