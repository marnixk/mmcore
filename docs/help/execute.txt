name: EXECUTE
kind: command

Run the text of a string as if it had been typed as a program line. The string
is tokenised and executed immediately.

EXECUTE string$

  string$ - command or statement text, up to 255 characters

Variables are shared with the running program. The executed text has its own
control-flow context: a block IF, SELECT CASE or loop started in the string is
discarded when EXECUTE returns, and the caller's IF, SELECT and loop state is
unchanged. A GOTO or GOSUB in the string still branches away after EXECUTE
returns, and END stops the whole program. EXECUTE does not accept multi-line
block structures.

Example:

    X = 0
    EXECUTE "X = X + 5"
    PRINT X

    EXECUTE "PRINT 6 * 7"
