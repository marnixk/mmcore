name: PIXEL
kind: command

Set a pixel, or set many pixels from arrays. As a function, PIXEL(x, y)
returns that pixel's RGB. Optional page is a page number or FRAMEBUFFER.

PIXEL x, y [, colour]
PIXEL x(), y() [, colour | c()]
PIXEL pos().x, pos().y [, colour]
PIXEL(x, y [, page])

  x, y - pixel coordinates (scalars or both arrays)
  colour - RGB colour (default foreground; see ~COLOUR~); may be an array
  page - page or FRAMEBUFFER (function form)

x and y must both be scalars or both be arrays. TYPE arrays use arr().member
as a numeric view (see ~TYPE~). Mix with plain x() / y() arrays. If colour is
an array, each point uses that element. The number of pixels is the length of
the smallest array.

Example:

    PIXEL 10, 10, RGB(255, 0, 0)
    PIXEL XX(), YY(), CC()
    PIXEL pos().x, pos().y, RGB(WHITE)
    PRINT PIXEL(10, 10)
