name: PIXEL
kind: command

PIXEL x, y [, colour]
PIXEL x(), y() [, colour | c()]
PIXEL pos().x, pos().y [, colour]
PIXEL(x, y [, page])   (function)

Set the pixel at (x,y). colour defaults to the
current foreground (see COLOUR).
x and y must both be scalars or both be arrays.
TYPE arrays use arr().member as a numeric view
(see TYPE). Mix with plain x() / y() arrays.
If colour is an array, each point uses that
element. The number of pixels is the length of
the smallest array.
PIXEL(x,y) as a function returns that pixel's RGB.
Optional page is a page number or FRAMEBUFFER.

Example:  PIXEL 10,10,RGB(255,0,0)
          PIXEL XX(), YY(), CC()
          PIXEL pos().x, pos().y, RGB(WHITE)
          PRINT PIXEL(10,10)
