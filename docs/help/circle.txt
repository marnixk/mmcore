name: CIRCLE
kind: command

Draw a circle centred at (x, y). An optional fill colour paints the interior.

CIRCLE x, y, r [, lw] [, colour] [, fill]

  x, y - centre
  r - radius
  lw - line width (default 1)
  colour - outline colour (default foreground)
  fill - fill colour if given (as for ~BOX~)

Example:

    CIRCLE 100, 80, 30, 1, RGB(0, 255, 255)
    CIRCLE 100, 80, 30, 1, RGB(255, 255, 255), RGB(0, 0, 128)
