name: REBOOT
kind: command
alias: RESTART

Restart the Raspberry Pi. Saves settings, stops audio, and unmounts drives
first, then performs a hardware reset; Control does not return to the prompt.
Ctrl+Alt+Del on a USB keyboard does the same. If the reset never completes the
watchdog will reboot the board.

REBOOT
RESTART

Example:

    REBOOT
    RESTART
