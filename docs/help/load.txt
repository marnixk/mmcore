name: LOAD
kind: command

Load an image onto the current WRITE page.

LOAD [JPG|JPEG|PNG] file$ [, x, y [, colour]]

  file$ - image path
  x, y - top-left destination (default 0, 0)
  colour - treated as transparent (CMM2); integer 0-31 maps to the IBM palette

JPG/JPEG uses the JPEG decoder. PNG (and BMP/GIF/IMAGE as a keyword) uses the
PNG decoder. With no type keyword, .JPG/.JPEG selects JPEG; otherwise PNG.

Example:

    LOAD PNG "TEST.PNG"
    LOAD JPG "TEST.JPG", 0, 0
