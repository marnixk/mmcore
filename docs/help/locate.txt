name: LOCATE
kind: command

LOCATE [y] [, x] [, cursor]

Move the text cursor to character cell y, x
(row, then column; 0-based). On an 80x25 screen,
LOCATE 24,79 is the bottom-right cell. Omit y or x
to leave that coordinate unchanged. cursor is 0 to
hide the hardware cursor or 1 to show it, e.g.
LOCATE ,,0 and LOCATE ,,1. The next PRINT writes
at that cell. PRINT @(x,y) still uses pixels.
Query the cursor with MM.HPOS and MM.VPOS (pixels)
or POS() (column, 1-based).

Example:  LOCATE 1, 0 : PRINT "HELLO"
          LOCATE ,, 0
