name: LOCATE
kind: command

Move the text cursor to a character cell.

LOCATE [y] [, x] [, cursor]

  y - row (0-based; omit to leave unchanged)
  x - column (0-based; omit to leave unchanged)
  cursor - 0 hide hardware cursor, 1 show it
           (e.g. LOCATE ,,0 and LOCATE ,,1)

On an 80x25 screen, LOCATE 24,79 is the bottom-right
cell. The next ~PRINT~ writes at that cell.
PRINT @(x,y) still uses pixels. Query the cursor
with MM.HPOS and MM.VPOS (pixels) or POS() (column,
1-based).

Example:

    LOCATE 1, 0 : PRINT "HELLO"
    LOCATE ,, 0
    PRINT MM.HPOS, MM.VPOS
