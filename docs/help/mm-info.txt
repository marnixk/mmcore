name: MM.INFO
kind: command

Return information about the current graphics mode.

value = MM.INFO
value = MM.INFO(key)

  key - "MODE" (default returns mode + bits/100), "HRES", "AUDIO"
        ("HDMI" or "JACK"), "MIXGAP" (longest mixer gap in milliseconds
        since PLAY started), "UNDERRUN" (times the output queue was
        empty when the mixer ran), "AUDIORESET" (times PLAY RESET
        has re-initialised the audio backend), "FIRSTVOL" (the gain
        applied to the first mixed buffer after playback began; -1 if
        nothing has played yet), or "MP3BUF" (peak bytes the streaming
        MP3 decoder allocated; bounded, not the file size)

See also ~MM.INFO$~, ~MODE~, ~AUDIO_TARGET~.

Example:

    PRINT MM.INFO(MODE)
    PRINT MM.INFO("HRES")
