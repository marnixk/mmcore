name: ANSI
kind: command

TheDraw-class ANSI art editor with a CP437 80x25 canvas and TheDraw .TDF
font support. Draw with printable characters or CP437 paint glyphs, pick
from the 16 VGA colours, draw lines and flood-fill, stamp banner text with a
seeded TheDraw font, then save standard .ANS art and reopen it.

ANSI EDIT file$ [, font$]
ANSI LOAD file$ [, font$]
ANSI FONT file$ [, name$]
ANSI SAUCE file$

  file$ - .ANS art path (with or without .ANS); the editor creates it
  font$ - optional TheDraw .TDF font path opened with the canvas
  name$ - optional font name when a .TDF collection holds several fonts

ANSI EDIT opens the editor with a blank canvas, or loads file$ when it
already exists. A .TDF font given as font$ is loaded for text stamping.

    Type          place that character and advance
    Space         paint the current paint glyph (default a solid block)
    Arrows        move the cursor
    Enter         start a new line
    BS            move the cursor left
    DEL           erase the cell under the cursor
    Alt+C         cycle the foreground colour
    Alt+B         cycle the background colour
    Alt+0..9      pick foreground colour 0..9
    Alt+P         cycle the paint glyph (solid, shades, space, ...)
    Alt+T         toggle .TDF text stamping (needs a font)
    Alt+L         toggle line mode: cursor moves draw a line
    Alt+F         flood-fill the matching region
    Alt+S         save file$ as ANSI
    Ctrl+Z        undo the last change
    Esc, Alt+X    quit

In text mode each typed character is rendered from the loaded .TDF font and
the cursor advances by the glyph width plus the font's letter spacing. Block,
Colour and Outline fonts are supported; Outline letters map to the CP437
box-drawing set and a space advances by the letter spacing.

A .TDF collection may hold up to 34 fonts. ANSI EDIT, ANSI LOAD and ANSI FONT
use the first font unless name$ selects another. ANSI FONT only reports the
font ("TDF <name> type=<n> spacing=<n> glyphs=<n>") without opening the
editor.

Saving writes standard ANSI escape sequences: rows are separated by CR/LF and
colours use the 30-37/40-47/90-97 SGR codes, so other viewers (including
~FILES~ paging) render the art. Loading tolerates a trailing SAUCE record and
an EOF (0x1A) marker. ANSI SAUCE appends a minimal SAUCE00 record after the
EOF so the file also carries metadata.

Example:

    ANSI EDIT "A:/art/TITLE.ANS", "A:/fonts/tdf/mono/STANDARD.TDF"
    ANSI FONT "A:/fonts/tdf/color/BLOCK.TDF"
    PRINT "saved to A:/art/TITLE.ANS"

The seeded fonts live under A:/fonts/tdf/ (see ~FILES~); ~SPRITE~ EDIT and
friends cover pixel art rather than character-cell ANSI art.
