name: JSON_PARSE
kind: command

Fill a TYPE variable from a JSON string. Object keys match member names
case-insensitively. Missing keys, extra keys and null leave members unchanged.

JSON_PARSE json$, var

  json$ - JSON text
  var - TYPE variable to fill

JSON bool becomes INTEGER 0 or 1. JSON number to INTEGER truncates toward zero;
overflow is an error. A string longer than a member's LENGTH is an error. Nested
objects fill nested TYPEs. JSON arrays fill array members (extra ignored).

Example:

    JSON_PARSE js$, w
    PRINT w.temp
