name: CONNECT
kind: command

Open a telnet-style TCP session to a host. Incoming bytes (including ANSI) are
shown on HDMI and serial. Available TCP data is drained each poll so a large
burst is not truncated. Starts in line mode with local echo.

CONNECT host$, port

  host$ - IP address or DNS name
  port - TCP port number

Telnet IAC WILL ECHO turns local echo off; IAC SGA switches to character mode.
Enter then sends CR only (not CR LF) so BBS hosts do not treat LF as a second
key. In line mode, Enter sends CR LF. USB Backspace (DEL) is sent as BS;
of backspace erases instead of inserting a glyph. Esc is sent to the host;
press Esc twice or wait briefly to flush a lone Esc. Ctrl+], F10, or Alt+X
quits. Alt+F opens a File menu with Exit.

Without Ethernet or Wi-Fi, CONNECT reports Network not available. Connect
after the network is up (OPTIONS WIFI or OPTION ETHERNET ON, then IPCONFIG).
DNS and the TCP handshake may take up to about 25 seconds.

Example:

    CONNECT "192.168.1.10", 23
