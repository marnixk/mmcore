name: CONNECT
kind: command

CONNECT host$, port

Open a telnet-style TCP session to host$ on port.
Incoming bytes (including ANSI) are shown on HDMI
and serial. Available TCP data is drained each
poll so a large burst is not truncated. Starts in
line mode with local echo.
Telnet IAC WILL ECHO turns local echo off; IAC
SGA switches to character mode. Enter then sends CR
only (not CR LF) so BBS hosts do not treat LF as a
second key. Line mode still sends CR LF.
USB Backspace (DEL) is sent as BS; local echo of
backspace erases instead of inserting a glyph.
Esc is sent to the host; press Esc twice or wait
briefly to flush a lone Esc.
Ctrl+], F10, or Alt+X quits. Alt+F opens a File
menu with Exit.

QEMU has no network device; CONNECT then reports
Network not available (or DNS/TCP failure on
hardware) and returns to the prompt. On hardware,
wait for Wi-Fi/DHCP first (OPTIONS WIFI), then
CONNECT uses Circle TCP (about 25s for DNS+SYN).

Example:  CONNECT "192.168.1.10", 23
