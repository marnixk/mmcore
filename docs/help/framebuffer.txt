name: FRAMEBUFFER
kind: command

Create and use an off-screen drawing buffer. MODE frees it. LOAD JPG cannot
target the framebuffer.

FRAMEBUFFER CREATE w, h
FRAMEBUFFER WRITE
FRAMEBUFFER BACKUP
FRAMEBUFFER RESTORE [x, y, w, h]
FRAMEBUFFER WINDOW x, y, page
FRAMEBUFFER CLOSE

  w, h - size; at least MM.HRES by MM.VRES and at most 1024x768
  x, y, w, h - restore region (optional)
  page - destination page for WINDOW

WRITE sends drawing to the buffer. WINDOW copies MM.HRES by MM.VRES from (x, y)
onto a page.

Example:

    FRAMEBUFFER CREATE 640, 480
    FRAMEBUFFER WRITE
    BOX 10, 10, 40, 40, 1, RGB(255, 0, 0), RGB(255, 0, 0)
    FRAMEBUFFER WINDOW 0, 0, 0
