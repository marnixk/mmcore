name: DATA
kind: language
alias: READ, RESTORE

Store literal values in the program for READ. RESTORE rewinds the DATA pointer.

DATA item [, item...]
READ var [, var...]
RESTORE [line]

  item - numeric or string literal
  var - variable to receive the next DATA value
  line - optional line number; RESTORE without it rewinds to the first DATA,
         or with it to the first DATA at or after that line

Example:

    DATA 10, 20, 12
    READ A, B, C
    PRINT A + B + C

    RESTORE
    READ A
    PRINT A
