name: DIR
kind: command
alias: LS, LIST FILES

List files in the current directory, or matching an optional path/wildcard.
LS and LIST FILES are the same listing (CMM2 names). This is not the dual-pane
file manager; use ~FILES~ for that.

DIR [spec$]
LS
LIST FILES

  spec$ - path or wildcard (optional)

Example:

    DIR
    DIR "A:/*.PNG"
    LS
    LIST FILES
