name: LINE INPUT
kind: command
alias: LINEINPUT

Read one line from an open file or TCP stream into a string variable. TCP reads
are non-blocking: an empty string if no complete line is waiting.

LINE INPUT #fn, var$

  #fn - open disk file or OPEN "TCP:host:port"
  var$ - string variable

Example:

    OPEN "N.TXT" FOR INPUT AS #1
    LINE INPUT #1, A$
    CLOSE #1
