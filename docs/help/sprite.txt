name: SPRITE
kind: command

Sprites drawn over PAGE DISPLAY. Missing image files create an empty placeholder.

SPRITE LOADPNG n, file$ [, colour]
SPRITE READ n, x, y, w, h [, page]
SPRITE SHOW n, x, y [, layer]
SPRITE HIDE n
SPRITE MOVE n, x, y
SPRITE CLOSE n | CLOSE ALL

  n - sprite number
  file$ - PNG path (with or without .PNG)
  colour - key colour treated as transparent
  x, y, w, h - position or READ rectangle
  page - source page for READ
  layer - display layer for SHOW

Example:

    SPRITE LOADPNG 1, "SHIP.PNG"
    SPRITE SHOW 1, 40, 40, 1
