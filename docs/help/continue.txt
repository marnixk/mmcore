name: CONTINUE
kind: language
alias: CONTINUE FOR, CONTINUE DO

Skip to the NEXT or LOOP of the current loop, then test the loop condition.

CONTINUE FOR
CONTINUE DO

Example:

    FOR I = 1 TO 3
      IF I = 2 THEN CONTINUE FOR
      PRINT I
    NEXT I

    I = 0
    DO
      I = I + 1
      IF I = 2 THEN CONTINUE DO
      PRINT I
    LOOP UNTIL I = 3
