mmCore Help

Type ~ME~ for a short introduction. Bare HELP opens this Overview. Escape
returns to the prompt.

  +Orientation-------------------------+ +Quick Reference-----------------+
  | ~USING HELP~                       | | ~ASCII CHARACTER CODES~         |
  | ~SYNTAX CONVENTIONS~               | | ~KEYBOARD SCAN CODES~           |
  +------------------------------------+ +--------------------------------+

Also: ~CONTENTS~ (command map)  ~INDEX~ (A-Z)  ~HELP~ (viewer)
      ~FUNCTIONS~ (math and strings)

Control Flow

    ~FOR~ - counted loop with optional STEP
    ~DO~ - general loop with WHILE/UNTIL
    ~WHILE~ - loop while a condition is true
    ~IF~ - conditional branch (ELSEIF/ELSE IF)
    ~SELECT CASE~ - multi-way branch (CASE ELSE)
    ~GOTO~ - jump to a line label
    ~GOSUB~ - call a line subroutine
    ~ON~ - ON GOTO/GOSUB/KEY/COM/TIMER/PLAY/PEN/STRIG/ERROR
    ~EXIT~ - leave a loop or routine early
    ~CONTINUE~ - skip to the next iteration
    ~END~ - end program or close IF/SELECT/SUB/FUNCTION
    ~REM~ - comment to end of line

Variables and Types

    ~DIM~ - declare variables and arrays
    ~LOCAL~ - declare local variables
    ~STATIC~ - declare static locals
    ~CONST~ - declare named constants
    ~TYPE~ - define a structured type
    ~LET~ - assign a value
    ~DATA~ - embedded program data
    ~CLEAR~ - clear variables
    ~INC~ - increment a variable
    ~DEC~ - decrement a variable

Procedures

    ~SUB~ - define a subroutine
    ~FUNCTION~ - define a function
    ~CALL~ - call a SUB by name
    ~RUN~ - run the program

Console and Text I/O

    ~PRINT~ - write text to the console
    ~INPUT~ - read values from the console
    ~LINE INPUT~ - read a whole line
    ~LOCATE~ - position the text cursor
    ~CLS~ - clear the screen
    ~INKEY$~ - read a key without waiting
    ~PAUSE~ - wait for a timed delay
    ~VSYNC_WAIT~ - wait for vertical sync

String Operations

    ~MID$~ - extract or assign a substring
    ~CAT~ - append text to a string variable
    ~SORT~ - sort an array
    ~FUNCTIONS~ - LEN LEFT$ RIGHT$ and more

Math Functions

    ~MATH~ - array and matrix math
    ~RANDOMIZE~ - seed the random generator
    ~FUNCTIONS~ - ABS SIN COS SQR and more
