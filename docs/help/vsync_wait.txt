name: VSYNC_WAIT
kind: command

Wait until the next display refresh (60 Hz). Use at the end of a game or
animation loop to cap the frame rate to the monitor. On hardware this waits for
HDMI vblank; on QEMU it waits 16 ms per call. Ctrl+C / BREAK still aborts a
running program.

VSYNC_WAIT

Example:

    DO
      PAGE COPY 1 TO 0
      VSYNC_WAIT
    LOOP
