name: PRINT
kind: command
alias: ?

Write values to the console, or to an open file or TCP stream.

PRINT [expr] [;|, expr]...
PRINT #fn, expr [;|, expr]...
?

  expr - value to print
  #fn - open disk file or OPEN "TCP:host:port"
  ; - suppress the trailing newline when last
  , - insert a space between items

Bare PRINT prints a blank line. Each PRINT appears on the console as it runs.
Position text with PRINT @(x,y) (pixels) or LOCATE row, col (character cells).

Example:

    PRINT 6 * 7
    ? 6 * 7
    PRINT
    PRINT #1, "HELLO"
    PRINT @(8, 8); "HI"
