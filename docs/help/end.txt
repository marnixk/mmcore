name: END
kind: command
alias: END CSUB, END DEFINEFONT

Stop a running program.

END

END alone stops the program (see also ~STOP~). The block-closing forms
END IF / ENDIF, END SELECT, END SUB, END FUNCTION and END TYPE are documented
with their opening keyword: ~IF~, ~SELECT~, ~SUB~, ~FUNCTION~ and ~TYPE~.

Example:

    PRINT 42
    END
