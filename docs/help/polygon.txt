name: POLYGON
kind: command

Draw a closed polygon (at least 3 vertices). Filled polygons are triangulated
from the first vertex.

POLYGON x1, y1, x2, y2, x3, y3... [, colour] [, fill]

  x, y - vertex coordinates (at least three pairs)
  colour - outline colour (optional)
  fill - fill colour (optional; last arguments)

Example:

    POLYGON 10, 10, 40, 10, 25, 30, RGB(255, 0, 0)
