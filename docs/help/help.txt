Open interactive help (QuickBASIC-style). HELP and
IHELP are the same command. Keywords are
case-insensitive (help, HELP, Help CLS, ihelp).

HELP opens the Overview. HELP command (or
IHELP command) opens that topic; Escape then quits
back to the prompt. From the Overview, Escape quits.
After following a <link>, Escape goes back.
HELP BASIC opens ~Contents~. HELP INDEX opens the
A-Z ~Index~.

Mark a topic with tildes in the docs to make a
link, for example ~CLS~. Unmarked words are not
links even when they match a command name.

Move with arrows, Page Up, and Page Down.
Enter follows a <link>. A single Escape goes back
or quits from the Overview. Arrow keys still work.
Colours follow OPTION EDIT THEME (same palettes
as the editor).

Unknown topics stay on the ~Index~; they do not raise
?SYNTAX ERROR.
