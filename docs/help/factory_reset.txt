name: FACTORY_RESET
kind: command
alias: FACTORY RESET, FACTORY

Restore firmware OPTION defaults and rewrite the hidden settings file
(.mmbasic.ini): DEFAULT MODE 11, PROMPT CWD, EDIT THEME Slate. Programs and
other user files are kept. Wi-Fi credentials and Ethernet ON are cleared.

FACTORY_RESET
FACTORY RESET

Example:

    FACTORY_RESET
    FACTORY RESET
