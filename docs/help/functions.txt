name: FUNCTIONS
kind: command
alias: ABS, SIN, COS, TAN, ATN, ACOS, ASIN, RND, LEN, LEFT$, RIGHT$, INSTR, VAL, STR$, CHR$, ASC, EOF, LOF, LOC, TIMER, RGB, MAX, MIN, FORMAT$, BOUND, DEG, RAD, POS, CHOICE, TAB, SGN, EXP, LOG, PI, DATE$, TIME$, CWD$, UCASE$, LCASE$, HEX$, OCT$, BIN$, SPACE$, STRING$, FIX, SQR, SQRT, ATAN, ATN2, INT, PLAYING, MM.HRES, MM.VRES, MM.INFO, MM.VER, MM.DEVICE$, MM.CMDLINE$, MM.HPOS, MM.VPOS, KEYDOWN, CINT, EVAL

Catalogue of functions for use in expressions. Type HELP FUNCTIONS, or HELP
and the function name when it is listed as an alias of this topic.

FUNCTIONS

Strings: LEN ASC CHR$ STR$ VAL LEFT$ RIGHT$ MID$ UCASE$ LCASE$ SPACE$ STRING$
  INSTR HEX$ OCT$ BIN$ FORMAT$ INKEY$ KEYDOWN TAB
  INKEY$ maps VT100 arrows/F-keys to CMM2 codes (Up=128); see ~INKEY$~.

Math: ABS INT FIX CINT SQR/SQRT SIN COS TAN ATN/ATAN ATN2 ACOS ASIN RND SGN
  EXP LOG PI MAX MIN DEG RAD CHOICE BOUND EVAL MATH()

Graphics: RGB(r,g,b)|RGB("NAME")  PIXEL(x,y)
  MM.HRES MM.VRES MM.HPOS MM.VPOS MM.INFO(MODE)

Files: EOF(#n) LOF(#n) LOC(#n) CWD$ INPUT$(nbr,#n)
  Disk: LOC=seek pos  LOF=size  EOF=pos>=size
  TCP:  LOC=RX waiting  LOF=0  EOF=not connected
  INPUT$(nbr,#n) count first; TCP non-blocking

Other: PLAYING() DATE$ TIME$ TIMER POS
  MM.VER MM.DEVICE$ MM.CMDLINE$
  STRUCT() SIZEOF|OFFSET|TYPE|FIND
  JSON$(json$, path$)
  JSON_STRINGIFY$(var)
  DATE$= and TIME$= set the clock strings.

OPTION ANGLE DEGREES makes SIN/COS/TAN/ATN use degrees.

Example:

    PRINT LEFT$("MMBASIC", 2)
    PRINT RGB(255, 0, 0)
    PRINT MM.HRES, MM.VRES, MM.HPOS, MM.VPOS
    PRINT MM.CMDLINE$
    PRINT KEYDOWN(1)
