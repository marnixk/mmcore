name: SETTINGS
kind: command

Open the system-wide settings hub as a modal dialog. The hub lists categories
and each category holds its own controls; Esc backs out of a category to the
hub and closes from the hub, returning to the prompt.

SETTINGS
SETTINGS THEME name|n

  name - a theme name (bare or quoted) or its index

Categories:

  Appearance - the TUI theme picker (below)
  Network    - Wi-Fi / Ethernet / NTP status and pointers to the commands
  System     - boot destination, app PATH, prompt and theme summary
  Sound      - audio output and mute

Theme (Appearance)

The theme picker lists every built-in TUI theme and previews the highlighted
one live: the screen recolours as you move, and the choice is kept when you
press Enter. It sets the system-wide theme, the same one OPTION THEME sets, so
it applies everywhere the theme is used: FILES, WORDPAD, TERM, HELP, SPRITE,
PACKAGE, APPS and the rest of the themed chrome. The editor follows this theme
too unless a different editor-only theme is picked from EDIT's Theme menu (or
with OPTION EDIT THEME). It is saved to C:/.mmbasic.ini (A: if there is no SD
card) and survives a reboot.

Keys in the hub:

  Up / Down   move the category selection
  Enter       open the category
  Esc         close the hub

Keys in Appearance (Theme):

  Up / Down   move the selection (live preview)
  Enter       apply and save
  Esc         back to the hub, restoring the entry theme
  0-9         jump to a theme by index

Built-in themes, in order:

  0 Paper   1 Cloud   2 Snow   3 Night   4 Nord
  5 Slate   6 Forest  7 Violet 8 Turbo  9 Phosphor

Default is Slate. Turbo is the retro VGA palette; Phosphor is a green CRT.
Themes can also be chosen from a program with OPTION THEME name. To give the
editor its own look, pick from EDIT's Theme menu or use OPTION EDIT THEME;
SYSTEM there follows this system theme.

Example:

    SETTINGS
    SETTINGS THEME Nord
    SETTINGS THEME "Violet"
    OPTION THEME 8              ' same selection, no UI
    OPTION EDIT THEME TURBO     ' editor-only override
    COLOUR THEME("TEXT_FG"), THEME("TEXT_BG")
