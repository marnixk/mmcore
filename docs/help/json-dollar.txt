name: JSON$
kind: command
alias: JSON

JSON$(json$, path$)

Query a JSON object stored in a STRING (255).
path$ uses dotted keys and [n] array indexes:
  main.temp   weather[0].description
Missing keys, null, objects and arrays return "".
Invalid JSON is an error.
HELP JSON_PARSE and JSON_STRINGIFY$ map a TYPE.

Example:
  PRINT VAL(JSON$(js$, "main.temp"))
  PRINT JSON$(js$, "name")
