name: ETHERNET
kind: command
alias: OPTION ETHERNET

Turn wired Ethernet on or off.

OPTION ETHERNET ON
OPTION ETHERNET OFF

ON starts DHCP on the Ethernet port and turns off Wi-Fi auto-join. Credentials
for WIFI are kept. Only one interface is active: enabling Ethernet disables
Wi-Fi; OPTIONS WIFI / OPTION WIFI disable Ethernet. Switching after the stack
is up needs REBOOT. If ON is saved, Ethernet initialises at boot. IPCONFIG
shows Interface: Ethernet. If Ethernet is not available, ON reports Ethernet
not available. The setting is saved across reboots.

Example:

    OPTION ETHERNET ON
    IPCONFIG
    OPTION ETHERNET OFF
