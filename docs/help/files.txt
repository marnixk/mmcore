name: FILES
kind: command

Open the dual-pane file manager (not a DIR listing). Navigate drives and
folders. Enter on a directory opens it. Enter on a .BAS file RUNs it. View
(v/F3) previews PNG/JPG, plays MP3/XM/MOD when supported, opens .ANS/.ASC/.DIZ
through an ANSI viewer, previews .TDF fonts, and also shows .BAS/.INC/.TXT with
colour. Tab switches panes. q or Esc leaves FILES.

An image preview reads the picture size, switches to the smallest graphics
MODE that fits it, and draws it centred with the file name and its dimensions
shown along the top. Left/Right arrows step through the other images in the
folder. Press Enter or Esc to return to the file manager; the previous MODE is
restored.

An ANSI preview interprets the file as a VT100/ANSI terminal would (SGR
colours, cursor movement, erase, save/restore) using IBM VGA CP437 glyphs and
the standard 16-colour palette on a black screen in the current MODE. Lines
auto-wrap at 80 columns like a real ANSI terminal, whatever the MODE. Up/Down
scroll a row and PgUp/PgDn a page through art taller than the screen; content
is kept, so earlier rows remain reachable. Press F to toggle the authentic
80x25 view (MODE 2 640x400, the full-screen TERM pane), and F again to return
to the MODE the preview opened in. Enter or Esc returns to the file manager.

A .TDF preview decodes the TheDraw font with the same decoder as TDF.BAS
(~TDF~) and draws a specimen of its glyphs: the font name, then printable
ASCII 33-126 wrapped across the screen. It uses the current MODE's character
grid (no MODE switch), Up/Down scroll taller fonts, and Enter or Esc returns.
A file that is not a valid .TDF falls back to the file-info overlay instead of
failing.

FILES

Menus: Alt+L Left  Alt+F File  Alt+C Command  Alt+O Options  Alt+R Right.
Colours follow OPTION THEME (same palettes as the other themed apps).

The Command menu (or s in the F9 menu) has "FTP server". It serves the active
pane's folder over FTP on port 21 (passive data on port 1021), using the
current address from IPCONFIG, so a desktop FTP client can copy files to and
from the device. A modal dialog shows the root and address; all other keys are
ignored until Esc stops the server. A: (ramdisk), B: and the FAT drives all
work; requests cannot escape the chosen folder. Uploading to a path whose
folders do not exist yet creates them under the served folder.

Example:

    FILES
