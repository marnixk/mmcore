name: OPEN
kind: command

Open a disk file, or a TCP client stream. Stream numbers are 1 to 10.

OPEN file$ [FOR INPUT|OUTPUT|APPEND] AS #n
OPEN "TCP:host:port" [FOR INPUT|OUTPUT] AS #n

  file$ - disk path
  #n - stream number 1 to 10
  INPUT - read
  OUTPUT - create/truncate
  APPEND - write at the end

TCP: host is an IP or DNS name; port is required. No FOR means both directions.
One TCP client at a time. CONNECT and TERM use the same socket. QEMU TCP needs
-device usb-net and OPTION ETHERNET ON; otherwise OPEN
"TCP:..." fails (network not available).

Example:

    OPEN "A.TXT" FOR OUTPUT AS #1
    PRINT #1, "HELLO"
    CLOSE #1
    OPEN "TCP:192.168.1.50:80" AS #1
