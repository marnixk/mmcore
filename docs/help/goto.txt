name: GOTO
kind: language

Jump to a numbered program line or a label. A label is an identifier at the
start of a line, ended with a colon.

GOTO line
GOTO label

  line - program line number
  label - label name (without the colon)

Example:

    GOTO Skip
    PRINT "NO"
Skip:
    PRINT 42

    GOTO DONE
    PRINT "NO"
DONE:
    PRINT 42
