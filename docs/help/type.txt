name: TYPE
kind: language
alias: END TYPE

Define a user type. DIM var AS name, DIM arr(n) AS name, LOCAL and STATIC.
SUB/FUNCTION parameters and FUNCTION return use AS name too. PIXEL and MATH
accept arr().member as a view of that field across the array. See ~STRUCT~.
LIST TYPE [name] lists definitions.

TYPE name
  member AS INTEGER|FLOAT|STRING [LENGTH n]
  member AS othertype
END TYPE

  name - type name
  member - field name
  LENGTH n - optional maximum length for a STRING member (default: no limit);
             assigning more than n characters raises ?OVERFLOW

Members: INTEGER (64-bit), FLOAT, STRING, nested types. INT means INTEGER
inside TYPE. A STRING member without LENGTH grows automatically like a plain
string variable, with no cap other than available memory (multi-megabyte
values work). LENGTH n keeps the member dynamic up to a maximum of n
characters, so programs that rely on ?OVERFLOW keep working. Access with
var.member and arr(i).member. Whole-struct assign copies the same type only
(deep copy, including STRING members). A period can appear in a variable name
unless the left side is a TYPE variable.

A STRING member is stored out of line, so STRUCT(SIZEOF) reports the fixed
record size (a STRING slot is 16 bytes) and not the characters held in it.
STRUCT SAVE/LOAD write a versioned variable-length binary format that carries
STRING members in full; see ~STRUCT~.

Example:

    TYPE Point
      x AS INTEGER
      y AS INTEGER
    END TYPE
    DIM p AS Point = (10, 20)
    PRINT p.x
