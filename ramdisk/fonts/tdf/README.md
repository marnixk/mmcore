# TheDraw TDF fonts (curated subset)

Forty-one [TheDraw](https://en.wikipedia.org/wiki/TheDraw) `.TDF` font files from
the [Roy/SAC TheDraw TDF Fonts Collection](https://www.roysac.com/images/galleries/ZIP/ROYS-THEDRAW_TDF_FONTS_COLLECTION.ZIP)
(`THEDRAWFONTS/` inside the archive). They appear on the A: drive under three
category folders:

```
A:/fonts/tdf/mono/    plain single-colour text faces
A:/fonts/tdf/color/   fonts whose glyphs carry colour attributes
A:/fonts/tdf/deco/    single-colour decorative / outline / display faces
```

For example `A:/fonts/tdf/mono/STANDARD.TDF` and `A:/fonts/tdf/color/BLOCK.TDF`.

This folder is **not** the full RoySAC pack (hundreds of fonts and preview
assets). It is the approved shortlist for mmCore ramdisk seeding (~397 KiB total;
see issue #554). PREVIEW images from the zip are not included.

Individual font authorship varies across the BBS/ANSI scene; the collection was
assembled and distributed by Carsten “Roy/SAC”. mmCore redistributes only this
fixed subset for use with future TheDraw-related tooling (#511).
