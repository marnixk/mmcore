# TheDraw TDF fonts (curated subset)

Thirty [TheDraw](https://en.wikipedia.org/wiki/TheDraw) `.TDF` font files from the
[Roy/SAC TheDraw TDF Fonts Collection](https://www.roysac.com/images/galleries/ZIP/ROYS-THEDRAW_TDF_FONTS_COLLECTION.ZIP)
(`THEDRAWFONTS/` inside the archive). They appear on the A: drive as
`A:/fonts/tdf/<NAME>.TDF` (for example `A:/fonts/tdf/BLOCK.TDF`).

This folder is **not** the full RoySAC pack (hundreds of fonts and preview
assets). It is the approved shortlist for mmCore ramdisk seeding (~153 KiB total;
see issue #554). PREVIEW images from the zip are not included.

Individual font authorship varies across the BBS/ANSI scene; the collection was
assembled and distributed by Carsten “Roy/SAC”. mmCore redistributes only this
fixed subset for use with future TheDraw-related tooling (#511).

Source archive (download once, extract only the listed `.TDF` names):

https://www.roysac.com/images/galleries/ZIP/ROYS-THEDRAW_TDF_FONTS_COLLECTION.ZIP
