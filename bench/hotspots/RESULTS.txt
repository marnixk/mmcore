Microbenchmark results. Profiler off (MMB_STMTPROF unset). TIMER is integer
milliseconds. ns/exec subtracts an empty FOR/NEXT of the same trip count.

Host: x86_64 Linux, native/mmbasic and native/mmcore, -O2 -g, SDL dummy for
gfx.bas. Not a Pi 400. This file is the run recorded for
docs/analysis/jetpack-inner-loop-hotspots.md.

Baseline used in the write-up: cached `a = a + 1` under OPTION DEFAULT INTEGER
with the trace cache on, 145 ns/exec.

the linear SUB/FUNCTION scan, about 1 ns per name per primary.
