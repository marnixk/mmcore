== Santa's Catch ==

A simple game that has you catch gifts and bonk the grinch on the head! 



= Run the game

To run this game on the CMM2, execute "main.bas" with the working directory 
set to where it lives.




= Controls

Move the paddle using 'Z' and 'V' left and right respectively.

Move Santa's mallet using the numpad arrow keys.

Bonk a grinch on the head by pressing '5', the middle button on the numpad.



= Rules of the game

To win at the game, try to get the highest score. 

Move the paddle on the left side of the screen and catch gifts. The more
gifts you have, the higher your score will be. If you miss a gift, you will lose one.

On the right side of the screen, grinches popup. Hit them with your Santa mallet before 
they come out too far! 

If you miss a grinch, they will take 5 gifts!

If you have less than zero gifts, the game will end: you lose.
